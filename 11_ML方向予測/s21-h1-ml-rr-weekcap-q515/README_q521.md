## 読み方
- 成績（t・正の年・α）は明確に改善し、上乗せ条件も超えた。落ちたのは max_dd のみで、これは r（1 トレードのリスク、σ 目標 0.25%/日から自動決定）の水準で決まる量。r を下げれば max_dd は比例して浅くなるが、t は変わらない
- ただし r や σ 目標を結果を見て変えるのは事後の調整になる。関門のリスク値（σ 目標・max_dd・t）は taichi の決めること（運用ルール）なので、ここでは判断を仰ぐ

## 確認（2026-11-09・taichi と Claude の読み合わせ）
