# MT5 側の道具（bot 制作・2026-10-27）

bot（S21・S23・S17b）を「記録だけ」から「MT5 で動く」へ進めるための、MT5 の中で動く道具。**どちらも売買はしない（読むだけ）**。Mac の MT5 でも Windows の MT5 でも動く（MQL5 なので Python の MetaTrader5 パッケージは要らない）。

| ファイル | 種類 | すること | 何に使う |
|---|---|---|---|
| `S21_SymbolSpecs.mq5` | スクリプト（1 回走らせて終わり） | 全銘柄の仕様（スワップの型と値・3 倍デー・桁・契約サイズ・tick value・最小ロット・現在のスプレッド）を CSV に書き出す | ① S23・S17b のスワップ込みの出し直し（taichi 待ち 1 がこれで済む） ② 業者の銘柄名との対応づけ ③ 実弾のロット計算（R → ロット） |
| `S21_SpreadLogger.mq5` | サービス（MT5 を開いている間ずっと） | S21 の 19 銘柄＋BTC・ETH のスプレッドを 5 秒おきに測り、1 時間ごとに平均・最小・最大・毎時 0 分の値を CSV に足す | 運用規程 §4 の実弾条件③「実測コストが 1R の 3% 以内」と、Q539（損益分岐はスプレッド約 2.16 倍）を実際の口座で確かめる |

## 入れ方（最初の 1 回・5 分）

1. MT5 を開き、デモ口座（Fintokei でも XM でも。**実際に bot を動かす予定の業者**）でログインする。
2. メニュー「ファイル」→「データフォルダを開く」→ `MQL5` を開く。
3. `S21_SymbolSpecs.mq5` を `MQL5/Scripts/` に、`S21_SpreadLogger.mq5` を `MQL5/Services/` にコピーする。
4. MT5 のナビゲーター（Ctrl+N）で右クリック →「更新」。出てこなければ、ファイルをダブルクリックして MetaEditor で開き、「コンパイル」（F7）。エラーが出たら、その文面をそのまま Claude に貼る。

## 使い方

- **仕様の書き出し**: ナビゲーターの「スクリプト」→ `S21_SymbolSpecs` をチャートにドラッグ → OK。完了の通知が出て、`MQL5/Files/symbol_specs_YYYYMMDD_HHMM.csv` ができる。その CSV を `~/ワークスペース/検証/フォワード/MT5/` にコピーして「仕様を出した」と言えば、Claude が次を回す:
  ```
  ~/ワークスペース/作業層/大容量/venv_forward/bin/python \
    ~/ワークスペース/検証/verification-lab/financial-engineering/s23-crypto-uptrend-long-q529/swap_from_mt5.py \
    --h1 ~/ワークスペース/作業層/大容量/crypto_h1_hist --specs <CSV のパス>
  ```
- **スプレッドの記録**: ナビゲーターの「サービス」→ `S21_SpreadLogger` を右クリック →「サービスを追加」→ 右クリック →「開始」。以後 MT5 を開いている間、`MQL5/Files/spreads_YYYYMM.csv` に 1 時間 1 行ずつ足される。止めるときは右クリック →「停止」。
  - 見つからない銘柄は「エキスパート」タブに「見つからない銘柄」と出る（業者の名前が違う。`Symbols` の入力で直せる）。
  - Mac がスリープしている間は測れない。測れた時間だけで集計する（休場・スリープの時間は行を書かない）。
